# Global Sports ID

Expo React Native app for player and coach discovery, messaging, trials, and offers.

## Next steps

1. Copy `.env.example` to `.env`
2. Add your Supabase URL and anon key
3. Run `supabase/schema.sql` in the Supabase SQL editor
4. Start the app with `cmd /c npm run web` or `cmd /c npm run android`
