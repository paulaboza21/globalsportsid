What is included:
- App source files
- Assets
- Supabase schema
- .env and .env.example
- package.json and package-lock.json
- app.json and eas.json

Important:
- This backup contains .env, which includes private project keys.
- Keep this folder private.
- Do not upload this folder publicly.

How to restore:
1. Copy this folder to a computer.
2. Open the project folder in VS Code.
3. Run npm install
4. Run npx expo start -c
5. Press w for web or a for Android

Recommended extra protection:
- Keep one copy on a USB
- Keep one copy on cloud storage you trust
- Keep the GitHub repo as your online code backup
